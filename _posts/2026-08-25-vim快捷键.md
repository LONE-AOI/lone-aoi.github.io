# VS Code + Vim 插件快捷键大全

## 🔹 **模式切换**
| 按键 | 功能 |
|------|------|
| **i** | 进入插入模式（光标前） |
| **a** | 进入插入模式（光标后） |
| **I** | 进入插入模式（行首） |
| **A** | 进入插入模式（行尾） |
| **o** | 向下插入新行 |
| **O** | 向上插入新行 |
| **Esc / Ctrl+[** | 返回普通模式 |
| **Ctrl+C** | 返回普通模式（不检查缩写） |
| **v** | 进入可视模式（字符选择） |
| **V** | 进入可视行模式 |
| **Ctrl+V** | 进入可视块模式（列选择） |

## 🔹 **搜索与替换**

|------|------|

| **?** | 向上搜索 |
| **n** | 下一个匹配项 |
