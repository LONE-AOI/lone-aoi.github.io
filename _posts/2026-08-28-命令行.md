# 命令行是啥
我们在一些影视作品中，常常看到这样的对~~虚假的~~黑客的描写：
屏幕上，一堆神秘的英文字符在一坨黑色的界面上翻滚。

这就是**命令行 Command Line CLI**，也叫**终端**、**控制台**、**Shell**，是一种*基于文本的交互界面*。与我们平常使用的**图形用户界面 GUI**不同，命令行完全依靠*输入文本指令*来操作电脑。

我们在命令行界面通常看到类似：`[用户名@主机名 当前目录]$ 一闪一闪kirakira`。这是**提示符**，它告诉你电脑已经准备就绪，等待你的指令；而当你输入指令并按下回车，电脑就会立即执行。
# 为啥要学它
你也能想到，命令行是远古时代的产物，最早的码农就在这片土地上劳作。但时至今日，命令行也有它的优势：
- *快*：只要你打字手速快，它绝对比鼠标更高效
- *省*：没有花里胡哨的界面，节省资源
- *自动化*：把需要重复使用的命令写在脚本里，电脑就能自动执行重复性任务
- *专业*：仍然有许多专业工具没有GUI~~，因为都懒得写那种没用的东西~~。
# 要学什么
一般来说，需要了解的命令行有两个：
- Windows的**CMD**或**PowerShell**
- Linux的**Bash**

学习命令行，千万不能死记硬背！要像使用鼠标一样，基于目的自然地去记忆命令格式。
